# Raiz & Lua — Landing page de produtos holísticos

Site estático (HTML, CSS e JavaScript puro) para uma loja de cristais, velas, incensos, ervas e kits de ritual.

## Páginas

- `index.html` — home
- `cristais.html` — categoria com filtros por intenção e formato
- `produto.html` — página de produto (aroma, quantidade, sacola)

## Rodar localmente

Abra `index.html` no navegador, ou rode o servidor local:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

e acesse http://localhost:8080.

## A preencher

Preços, frete, CNPJ, cidade e ingredientes estão marcados com `[colchetes]` ou `R$ 00,00`.
